# Jan Walker — Books That Start Arguments

Author site for the Trivia & Fun Facts book series (Cars & Trucks, Family Table Books, seasonal).
Single self-contained `index.html` — fonts and covers inlined, no external requests.

- `index.template.html` — source template (tokens `{{FONT_*}}`, `{{COVER_*}}`)
- `build.py` — inlines fonts + covers, writes `index.html`

Live: https://jex-x-x.github.io/jan-walker-books/
